# MMP

> A simple picture viewing tool for macOS. 一个轻量的 macOS 看图工具，对标「WPS 看图」的基础功能。

**当前版本：1.5** ｜ [版本历史](#版本历史)

---

## 项目介绍

MMP 是一个用 Swift 从零写的 macOS 图片查看器，目标是把「看图」这件事做到**快、轻、顺**：

- **快**：冷启动即出图，切图无等待。解码走系统 ImageIO，并按窗口大小降采样——100MP 的照片也不会撑爆内存；放大时再按需重新高清解码。
- **轻**：不依赖任何第三方库，不依赖 `.xcodeproj`。核心就是 5 个 Swift 文件加一条 `build.sh`，产物是几百 KB 的 `.app`。
- **顺**：双击一张图就把整个文件夹接管过来，方向键一路看下去；滚轮缩放、拖拽平移、缩略图定位，键盘和触控板都能舒服地用。

**为什么不用系统「预览」？** 预览是个通用文档工具，看图时：文件夹内翻页要靠缩略图栏或手势，缩放藏在菜单和工具栏里，GIF 也只是静默首帧。MMP 把「顺着看一个文件夹」和「放大看细节」做成第一优先级——方向键切图、滚轮缩放、右下角缩略图实时告诉你看到的是原图的哪一块。

**可以拿来做什么**：设为系统默认看图软件后，在访达里双击任意图片就是 MMP；也适合当本地图片素材的快速浏览工具——按文件名自然序一路过片，随手放大检查细节，GIF 动图直接看、还能逐帧抠。

## 功能特性

### 浏览

- **打开常见图片格式**：PNG / JPEG / HEIC / HEIF / GIF / TIFF / BMP / WebP / JPEG2000 与部分 RAW 走系统 ImageIO；SVG 由 AppKit 渲染兜底。无需任何第三方依赖。
- **一次打开，一个窗口，看完整个文件夹**：双击任意一张图片，自动载入同文件夹下的所有图片（按访达的自然排序），用 `←` `→` 方向键或窗口两侧的圆形箭头按钮轮播。
- **大图不卡**：解码时按窗口大小降采样（Retina 感知），只解到显示所需的尺寸。

### 缩放

- **滚轮 / 触控板双指捏合缩放**，以光标位置为锚点——想看哪里就把哪里放大到鼠标下。
- **放大后拖拽平移**；也支持键盘 `↑` `↓`、菜单和底部控制条的 `＋` `－` 按钮。
- **右下角缩略图**：放大时自动出现，白色方框实时标出当前可视区域在原图中的位置，随时知道自己"看到哪儿了"。
- **按需高清解码**：放大到一定程度会自动按缩放级别重新解码原图（带防抖，滚动时不会疯狂重解码），细节不糊；缩回去又自动降采样，内存不涨。
- 底部控制条实时显示缩放比例（20%～2000%），点一下百分比即可一键复位。

### GIF 逐帧播放

- 动图自动播放，帧延迟按文件内的实际时长走（对写入 0 的帧按浏览器惯例钳制到 0.1s，避免疯闪）。
- 控制条提供**播放 / 暂停**、**上一帧 / 下一帧**，并显示当前帧号（如 `12 / 80`）——用来逐帧看动图细节。

### 系统集成与设置

- **一键设为默认看图软件**：菜单栏 `MMP → 设为默认看图软件…`，或点窗口右上角 ⭐，批量接管全部常见图片格式。
- **设置菜单**：菜单栏「设置」或窗口右上角 ⚙️，两种浏览方式随时切换，选择自动记忆：

  | 模式 | 滚轮 / 双指滚动 | 方向键 |
  | --- | --- | --- |
  | 滚轮缩放 · 方向键切换图片（默认） | 缩放 | `←` `→` 切换图片 |
  | 滚轮切换图片 · 上下键缩放 | 切换图片 | `↑` `↓` 缩放 |

  注：触控板双指捏合在两种模式下都用于缩放；`⌘+` `⌘-` `⌘0` 在任何模式下都能缩放。

### 快捷键速查

| 操作 | 快捷键 |
| --- | --- |
| 打开图片… | `⌘O` |
| 上一张 / 下一张 | `←` / `→` |
| 放大 / 缩小 | `⌘+` `⌘-`，或 `↑` `↓` |
| 重置缩放（回到适应窗口） | `⌘0`，或点底部百分比 |
| GIF 播放 / 暂停 | `空格` |
| GIF 上一帧 / 下一帧 | 底部控制条按钮，或「浏览」菜单 |
| 退出缩放 / 关闭窗口 | `Esc`（未缩放时关闭窗口） |
| 关闭窗口 | `⌘W` |
| 退出 MMP | `⌘Q` |

## 版本历史

### 1.5 — 2026-10-03

**缩放浏览 + GIF 动图 + 个性化设置**，从"能看图"到"看得清、看得细"。

新增：

- **缩放**：滚轮（以光标为锚点）与触控板捏合缩放，`⌘+` `⌘-` `⌘0`、`↑` `↓` 亦可；放大后拖拽平移；缩放范围 20% ～ 2000%。
- **右下角缩略图**：放大时自动浮现，白色方框标出当前可视区域在原图中的位置。
- **按需高清解码**：按缩放级别防抖重新解码原图，放大看细节不糊，缩小时自动降采样释放内存。
- **GIF 逐帧播放**：逐帧解码并读取每帧延迟（≤0.02s 钳制到 0.1s）；自动播放，空格暂停，支持逐帧前进/后退与帧号显示。
- **设置菜单**：两种浏览方式（滚轮缩放·方向键切换 / 滚轮切换·上下键缩放）单选项，菜单栏与窗口 ⚙️ 弹窗两处同步，`UserDefaults` 记忆。
- **控制条**：底部新增缩放控制（比例显示、一键复位、加减号）与 GIF 播放控制。
- `Esc` 行为细化：处于缩放状态时先退出缩放，再按一次才关闭窗口；放大时自动禁用"拖背景移动窗口"，让拖拽专心用于平移图片。

修正：

- 1.0 虽在文档与 Info.plist 中宣称支持 SVG，但实际解码会报错——现在改为 ImageIO 失败时自动退回 AppKit 渲染并按当前解码预算栅格化，SVG 真正可看、可放大。

### 1.0 — 2026-09-28

**首个可用版本**，打通"看图"主链路。

- 打开 PNG / JPEG / HEIC / HEIF / GIF / TIFF / BMP / WebP / JPEG2000 与部分 RAW（基于系统 ImageIO）。
- 双击一张图即载入同文件夹全部图片，按访达自然序浏览，`←` `→` 或两侧箭头按钮切换。
- 解码时按窗口大小降采样（Retina 感知），大图不撑内存。
- 一键把 MMP 设为系统默认看图软件（LaunchServices）。
- 支持拖拽图片到窗口、`⌘O` 打开、`Esc` 关闭窗口。
- 构建方式：`swiftc` 直编 + 手工组装 `.app` bundle + ad-hoc 签名，无需 Xcode 工程。

已知限制：GIF 只显示首帧，不支持缩放、旋转、裁剪与多窗口。

## 构建与安装

无需 Xcode 工程，一条脚本即可（需要安装 Xcode 命令行工具）：

```bash
./build.sh           # 构建，产出 build/MMP.app
./build.sh install   # 构建并拷贝到 /Applications
```

## 使用建议

1. 运行 `./build.sh install` 把 MMP 装进 `/Applications`。
2. 启动 MMP，点窗口右上角 ⭐（或菜单栏 `MMP → 设为默认看图软件…`）。
3. 之后在访达里双击任意图片，默认就是 MMP。

> 未安装到 `/Applications` 时系统可能在重启后忘记默认打开方式，脚本会提示。

## 技术栈

- **语言**：Swift 6.3
- **UI**：AppKit（窗口 / 菜单 / 键盘与滚轮事件监听）+ SwiftUI（界面布局与控件）
- **图片解码**：ImageIO / CoreGraphics（`CGImageSource` 降采样解码；GIF 逐帧提取 + 帧延迟；SVG 走 AppKit 栅格化兜底）
- **系统集成**：LaunchServices（`CFBundleDocumentTypes` 声明 + `LSSetDefaultRoleHandlerForContentType` 设置默认打开方式）
- **构建**：`swiftc` 直接编译 + 手工组装 `.app` bundle + ad-hoc 签名，不依赖 `.xcodeproj`
- **最低系统**：macOS 13.0

## 目录结构

```
Sources/MMP/
  MMPMain.swift      入口（NSApplication 启动）
  AppDelegate.swift  窗口 / 菜单 / 键盘与滚轮监听 / 文档打开
  ViewerModel.swift  浏览状态 / 缩放平移 / GIF 播放 / 设置
  ContentView.swift  SwiftUI 界面（缩放画布 / 缩略图 / 控制条）
  Support.swift      文件夹扫描 / 解码（含 GIF 逐帧、SVG 兜底）/ 设为默认
Tools/
  GenIcon.swift      生成 AppIcon.icns
  SelfTest.swift     无界面自测（扫描 / 解码 / 排序）
Resources/
  Info.plist         UTI 与文档类型声明
build.sh             一键构建脚本
```

## 已知限制（1.5）

- 少数使用「局部帧」优化的 GIF（每帧只存变化区域）可能出现残影——目前按整帧解码。
- GIF 放大浏览时不会重新高清解码（动图帧通常很小，影响有限）。
- SVG 由 AppKit 栅格化渲染，个别复杂矢量特性（滤镜、嵌入字体等）可能不完整。
- 不支持旋转、裁剪、多窗口。
